# 台灣ETF智慧選股與投資組合分析網站 - 使用說明

## 📖 網站概述

本網站提供一套完整的ETF篩選與投資組合分析工具，幫助投資者快速找到符合需求的台灣ETF，並透過數據驅動的方法構建最優化的投資組合。

**主要功能：**
- 🔍 多維度ETF篩選
- 📊 投資組合最佳化配置
- 📈 詳細績效分析與視覺化對比

---

## 🎯 快速開始（3步驟）

### 第一步：篩選ETF
1. 開啟網站後，在左側**篩選區**設定篩選條件
2. 也可以加入你常用的組合，不用每次再篩選一次
3. 選擇符合你的投資目標的ETF
4. 點擊「查詢」，系統自動更新結果

### 第二步：檢視相關性
1. 在中間區域查看選中ETF的**相關性矩陣**
2. 系統會自動排除高相關標的（相關係數 > 0.7）
3. 確保你的組合具有充分的多樣化

### 第三步：配置組合與分析
1. 選擇配置方法（均等權重或最大夏普比率）
2. 查看右側的**組合配置圓餅圖**與**績效圖表**
3. 對比個別ETF與組合的報酬率表現

## 📋 篩選區詳細說明

### 1️⃣ 最大超額報酬（Alpha篩選）

**什麼是超額報酬？**
- 相對於基準指數（台灣加權指數 ^TWII）的額外收益
- 衡量基金經理人的選股能力

**使用方式：**
- 設定報酬率範圍（例如：>15% p.a.）
- 選擇時間區間：1M / 3M / 6M / 1Y
- 系統自動篩選出在該期間超越基準的ETF

### 2️⃣ 熱門題材（分類篩選）

支援7大類別，可複選：

| 題材 | 說明 | 適合投資者 |
|------|------|---------|
| 高股息 | 配息政策積極的ETF | 追求現金流 |
| 科技 | 科技股、AI相關 | 看好科技成長 |
| ESG | 環保、社會責任相關 | 永續投資理念 |
| 槓桿反向 | 放大型或看空型 | 進階投資者 |
| 債券 | 公債、公司債 | 風險規避 |
| 商品 | 黃金、能源等 | 資產配置多元化 |
| 全球市場 | 跨國、新興市場 | 地域多樣化 |

**使用方式：**
- 勾選感興趣的題材（支援複選）
- 系統即時過濾，只顯示符合的ETF

### 3️⃣ 效率前緣（風險-報酬篩選）

**概念說明：**
- 橫軸：風險（年化波動率 %）
- 縱軸：報酬（年化報酬率 %）
- 每個點代表一檔ETF

**使用方式：**
1. 在散點圖上調整「風險容忍度滑桿」
2. 系統自動突出符合你風險上限的ETF
3. 點擊圖上任何點可查看該ETF詳細資訊

**建議：**
- 保守投資者：選擇左下方（低風險）的ETF
- 積極投資者：選擇右上方（高報酬）的ETF
- 平衡型：選擇中間位置的ETF

### 4️⃣ 流動性篩選

**為什麼重要？**
- 流動性好的ETF易於買賣，不易滑價
- 規模太小可能面臨下市風險

**篩選維度：**
- **日平均成交量**：設定最低門檻（例如：>100萬張）
- **資產規模（AUM）**：設定最低門檻（例如：>50億元）

**建議設置：**
- 保守：日均成交量 > 100萬、AUM > 50億
- 普通：日均成交量 > 50萬、AUM > 20億
- 靈活：根據個人交易習慣調整

### 5️⃣ 時間區間選擇

**影響範圍：** 以下所有計算都會採用所選時間區間

| 時間 | 適用情景 |
|------|--------|
| 3M | 觀察短期動能 |
| 6M | 平衡短期與趨勢 |
| 1Y | 評估1年表現 |
| 3Y | 觀察中長期穩定性 |

## 🔗 投資組合配置區

### 相關性矩陣（熱力圖）

**見上方選中的ETF列表後，會自動生成相關性矩陣。**

**顏色含義：**
- 🔴 深紅：高度正相關（>0.7）— 建議排除其一
- 🟡 黃色：中度相關（0.4-0.7）— 可接受
- 🟢 深綠：低相關（<0.4）— 最理想

**使用方式：**
1. 懸停滑鼠可看到精確相關係數
2. 勾選「自動排除高相關標的」（預設啟用）
3. 系統自動幫你選出多樣化的組合

**技巧：**
- 如想手動調整，可取消自動排除，自行勾選/取消ETF
- 追求最大多樣化：選擇綠色區域的組合

---

### 資產配置方法

選擇下拉菜單中的配置演算法：

#### 方法一：均等權重（Equal Weight）
- **配置規則**：每檔ETF分配相同比例（100% ÷ 檔數）
- **優點**：簡單易懂、定期再平衡好執行
- **適用**：初心者、懶人投資者
- **範例**：5檔ETF 各配 20%

#### 方法二：最大夏普比率（Max Sharpe Ratio）
- **配置規則**：系統透過數學最佳化，找出風險調整後報酬最高的配置
- **優點**：量化、數據驅動、自動避開風險集中
- **適用**：追求效率的進階投資者
- **計算**：使用均值-變異數最佳化演算法

**選擇建議：**
- 首次投資 → 均等權重
- 有一定投資經驗 → 最大夏普比率

## 📊 視覺化呈現區

### 1️⃣ 報酬率表現圖（折線圖）

**顯示內容：**
- 🔵 各個選中ETF的累積報酬率走勢（細線）
- 🟢 投資組合整體走勢（粗線，醒目顏色）
- ⚪ 大盤基準（台灣加權指數 ^TWII）（虛線參考）

**互動功能：**
- **懸停**：滑鼠移至圖上，顯示該時點所有線的數值
- **縮放**：雙擊圖表可重設；框選區間可放大
- **拖拉**：左右拖動時間軸
- **圖例切換**：點擊圖例可隱藏/顯示個別線條

**讀圖技巧：**
- 綠色粗線在上方 → 組合跑贏大盤
- 綠色粗線平穩無波動 → 組合風險低
- 個別線條波動大 → 該ETF波動率高

### 2️⃣ 夏普比率對比圖（橫條圖）

**比較指標：**
- 各個選中ETF的夏普比率
- 投資組合整體夏普比率
- 大盤基準夏普比率

**夏普比率說明：**
- 定義：(年化報酬 - 無風險利率) ÷ 年化波動率
- 數值越高 → 風險調整後報酬越好
- 通常 > 1.0 為優秀

**Tooltip 附加資訊：**
- 年化報酬率（Annual Return）
- 年化波動率（Annual Volatility）
- 最大回撤（Max Drawdown, MDD）— 投資期間最大跌幅

**讀圖建議：**
1. 找夏普比率最高的組合方案
2. 檢視其最大回撤是否在容忍範圍
3. 綜合判斷是否適合你的風險承受度

## ⚠️ 重要提示

### 風險警示
1. **過往績效不代表未來表現**
   - 本網站數據基於歷史價格計算
   - 市場環境變化可能導致未來表現不同

2. **相關性矩陣非靜態**
   - 不同市場環境下相關性會改變
   - 建議定期（每季度）重新檢視

3. **最大回撤風險**
   - 所有報酬都可能面臨短期回撤
   - 檢視「最大回撤」指標評估波動幅度

4. **流動性變化**
   - ETF流動性可能因市場狀況改變
   - 行情急跌時可能面臨買賣困難

### 免責聲明
- 本網站僅供投資參考，不構成投資建議

## 🔧 常見問題

### Q1：如何解釋相關係數 0.7 的門檻？
**A：** 相關係數範圍 -1 到 1，0.7 表示強正相關（一起漲跌）。超過 0.7 的兩檔 ETF 難以形成有效的風險分散。

### Q2：為什麼建議使用「最大夏普比率」？
**A：** 它在同樣風險下追求最高報酬，或同樣報酬下承受最低風險，是量化投資的黃金法則。

### Q3：組合需要多少檔 ETF？
**A：** 
- 最少：3-5檔（才能有效分散）
- 最多：10-15檔（超過容易管理困難，邊際效益遞減）
- 建議：5-8檔為最佳平衡

### Q4：多久要檢視一次組合？
**A：** 
- 查看月報酬：每個月檢視一次
- 檢視組合配置：每季度重新篩選一次
- 重大市況變化時：隨時評估

### Q5：如何在實際交易中使用？
**A：** 
1. 確定資金規模（例如 100,000 元）
2. 根據配置圖的百分比分配資金
3. 在證券商下單購買（建議使用定期定額分批佈局）
4. 設定提醒檢視日期

### Q6：能否套用槓桿 ETF 或反向 ETF？
**A：** 
- 可以，但須謹慎
- 槓桿型：適合短期操作，不適合長期持有
- 反向型：通常用於部分避險，不建議主要配置
- 建議占比不超過組合的 10%

## 🎓 投資小知識

### 名詞解釋
- **Alpha（超額報酬）**：基金相對於基準指數的額外報酬
- **Beta（系統性風險）**：衡量與大盤同步程度
- **Sharpe Ratio（夏普比率）**：風險調整後的報酬指標
- **Drawdown（回撤）**：從高點跌到低點的幅度
- **Correlation（相關係數）**：兩資產同向波動的程度
- **Volatility（波動率）**：資產價格變化的標準差

### 投資組合原則
1. **多樣化分散**：選擇相關性低的資產
2. **風險匹配**：選擇符合自身承受度的配置
3. **定期檢視**：市況變化時重新評估
4. **長期持有**：避免追高殺低
